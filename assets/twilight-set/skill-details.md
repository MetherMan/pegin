범위 숫자는 미터가 아닌 게임 좌표 단위다. 서버의 범위 판정은 대상과 후보 적 사이의 거리 `floor(sqrt(dx*dx+dy*dy)) <= areaRange`이며 사실상 원형이다. 시전 거리는 `abs(dx) <= range && abs(dy) <= range`로 검사하므로 같은 원형 반경으로 해석하면 안 된다. 이동·시전 체감에는 클라이언트 거리 설정도 관여한다.

네 스킬 모두 현재 `skillAttr=2`(대상 중심), `timer=0`, 추가 상태 효과 값 0이다. 대상 주변 각 적에 한 차례 피해를 계산한다. 불기둥·번개가 여러 프레임 이어지는 것은 시각 연출이며 지속 피해나 별도의 다단히트 판정은 없다. 브레이크레볼루션에는 현재 스킬 자체의 기절 효과가 없다. 장비가 주는 별도 효과와는 구분한다.

브레이크레볼루션은 데이터의 쿨타임 칸에 1이 있지만 `coolTimeIdx=0`이어서 별도 쿨타임 처리 분기를 건너뛴다. 근접/원거리 스킬의 공통 행동 대기는 2.5초, 마법은 1.5초이고 나머지 세 스킬에는 표의 별도 쿨타임이 적용된다. 표의 범위는 서버 설정이며 구형 클라이언트 설명문과 차이가 있다.

## 구형 화면 설명과의 차이

- 브레이크레볼루션: 화면 설명에는 기절, 근접 80이 남아 있지만 현재 요구치는 90이고 기절 설정이 없다.
- 데쓰패너트레이션: 화면 설명에는 목표까지의 경로 전체를 관통한다고 되어 있으나 현재 서버는 직선 판정(`skillAttr=3`)이 아니라 대상 주변 범위값 3이다.
- 데쓰파이어코룸헬·썬더볼트: 화면 설명에는 시전자 주변 공격이라고 되어 있으나 현재 서버는 모두 대상 중심이다. 설명문의 100레벨 표기도 실제 요구치 115와 다르다.
