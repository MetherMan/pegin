## 모델과 재질

롱보우 4,968 삼각형, 스태프 7,052 삼각형. 실루엣에 실제 두께와 둥근 단면을 만들고 구멍을 관통시켰습니다. 활줄과 손잡이는 원통이며 스태프에는 둥근 자루와 금속 고리가 있습니다. 앞뒤에는 확정 원화의 투영 UV, 측면에는 별도 금속 UV를 씁니다. 모든 부품을 하나의 텍스처 아틀라스와 애니메이션 메시 0으로 내보내어 부품이 캐릭터 원점에 남는 문제를 방지합니다. 세 LOD는 같은 모델입니다.

회전 시 속이 보이던 문제를 수정했습니다. 삼각분할 결과의 방향을 가정하지 않고 실제 좌표에서 바깥쪽을 향하게 정렬합니다. 세분화한 앞뒤 표면과 동일한 경계를 사용해 옆면을 닫고, 옆면 UV를 한 타일 안에 유지해 아틀라스 변환에서 경계가 다시 갈라지지 않게 합니다. `verify_closed_surfaces.py`가 최종 MOD의 열린 경계·잘못 연결된 면·뒤집힌 이음새·각 부품의 부피 방향을 검사합니다. 세 무기 모두 열린 경계와 뒤집힌 이음새 0개입니다.

`index.html`은 실제 MOD/WTM을 다시 읽은 `*-native.glb`를 표시합니다. 저장소에서 로컬 HTTP 서버를 켜고 `/assets/twilight-set/index.html`을 열어 정면·사선·옆면·뒷면을 볼 수 있습니다. `mt_longbow.glb`, `mt_staff.glb`는 부품이 분리된 편집본입니다.

양손검도 날 끝, 본체와 가드·폼멜의 두께를 분리했습니다. 실제 MOD에서 날 가장자리 약 0.0049, 본체 0.0338, 가드 0.0645입니다. 기존 관통부·보조 칼날·길이·손잡이 위치는 `assets/twilight/verify_design04.py`로 검증했습니다.

## 평타 이펙트

`DeicideOnline.exe`의 원래 `SetArrowInfo` 함수에 독립된 `.moon` 섹션을 추가합니다. 기존 `.stk16`, 진단 및 검선 패치를 보존하고, 19060~19080만 `mt_arrow`를 선택합니다. 다른 무기는 원래 `단궁기본`을 사용합니다. `mt_arrow.ms`는 원래 `arw_d1.ms`를 복제하여 리소스 이름만 변경했습니다. 투사체 31프레임·타격 19프레임의 RGB와 잔상 재질 RGB만 청색으로 곱했습니다. 알파, 모양, 이동, 소리, 속도, 판정 타이밍은 보존했습니다. 스태프의 이펙트는 변경하지 않았습니다.

## 재생성과 검증

Python 3.12, 저장소 runtime의 기본 라이브러리와 `requirements-build.txt`가 필요합니다. 추가 라이브러리 경로는 `.cache/weapon-build-deps`입니다. 게임 클라이언트 원본이 `runtime/client/GameClient`에 있어야 합니다.

- `runtime/python/python.exe -X utf8 tools/build_twilight_set.py`: 활·스태프·아이콘·평타 효과·아이템·이름 색상 재생성 및 검증.
- `runtime/python/python.exe -X utf8 tools/build_twilight.py`: 양손검 두께별 메시와 게임 파일 재생성.
- `runtime/python/python.exe -X utf8 tools/audit_skill_caps.py`: 현재 스킬 요구 레벨 보고서.
- `tools/apply_twilight_set.py`: 실행 중인 로컬 게임이 없을 때만 서버를 빌드·적용하고 임시 캐릭터 통합 검사.

검증 기록: `asset-validation.json`, `tooltip-validation.json`(80 조합), `arrow-hook.json`(전체 함수 실행 29 조합), `arrow-effect-validation.json`, `live-validation.json`. 실제 로컬 서버에서 42개 정의, 지급 권한, 장착, 강화 단계 전환, 재접속 유지와 기존 캐릭터 DB 보존을 통과했습니다. 그래픽 클라이언트 안의 실제 전투 화면 검사는 별도이며, 3D 미리보기와 서버 패킷 검증을 구분합니다.

클래스별 최고 스킬과 16개 특화 직업은 `skill-caps.md`, 최상위 네 스킬의 실제 연출·범위·구형 설명과의 차이는 `skill-details.md`에 정리했습니다.
