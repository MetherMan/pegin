# 쌍월 대장궁 · 세 번째 수정안(06)

사용자가 선택한 `blue-moon-v3/06-twin-crescent-regalia-swept.png`에서 만든 실제 게임용 입체 모델이다. 뒤로 휘어진 윗활대, 푸른 수정과 금색 테두리, 중앙 초승달을 유지했다.

- 사용자 후속 비율 조정: 완성안에서 전체 크기를 10% 줄였다. 전장 2.0044로 이전 H03의 1.7434보다 약 15.0% 길다.
- 손잡이 원점을 유지하고 전체 크기에 맞춰 손잡이도 90%로 축소했다. 손잡이와 활줄의 둥근 단면은 유지하며, 손가락 장착 본과 아이템 번호는 바꾸지 않는다.
- 윗활대 쪽을 더 길게 배분해 큰 장궁 느낌을 주면서 아래쪽 끝의 지면 간섭을 줄였다.
- 26,580 → 5,148삼각형, 네이티브 렌더 정점 79,740 → 15,444개(80.6% 감소).
- 전체 표면은 닫힌 볼륨이며, 둥근 손잡이·연속 활줄을 포함한다. 몸체 옆면 반두께는 최대 0.0324로 완성안 0.05보다 35.2% 줄었다.
- 원화의 색은 다시 그리거나 리샘플하지 않고 크롭과 UV 아틀라스 배치만 했다.

`tools/build_twin_moon_greatbow.py`로 재생성한다. `active-design.json` 및 기본 무기 빌더도 이 선택을 따른다. `build-validation.json`은 실제 MOD/WTM 재읽기, 닫힌 표면, 픽셀 보존, 삼각형 예산, 보호 파일 해시 검증 결과다. `attachment-validation.json`은 남녀 캐릭터의 실제 활 애니메이션을 이용한 지면 간섭 검사다. 브라우저 검수는 네이티브 파일을 다시 읽은 결과이며, 인게임 FPS 측정은 별개다.
