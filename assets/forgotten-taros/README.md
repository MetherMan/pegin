# 잊혀진 타로스

맵 번호 41. 기존 타로스(14)의 지형·배경 오브젝트·미니맵·로딩 리소스를 바탕으로 만든 별도 지역이다. 타로스의 미등록 포탈 표시 `!.MOD` 위치 (448.74, 264.03)에 이동 판정 (448, 264)을 등록했다. 난파선 오브젝트는 (349~363, 256~267)에 있다.

- 타로스 (448, 264) → 잊혀진 타로스 (443, 264).
- 잊혀진 타로스 (448, 264) → 타로스 (443, 264).
- 복사된 서쪽 출구 (60, 265)도 타로스 (443, 264)로 돌아간다.
- 도착 위치를 판정 밖으로 두어 즉시 왕복되는 현상을 막았다.
- 두 지역은 서버 월드 객체와 몬스터·플레이어 목록이 별도다.

## 커스텀 몬스터 배치 준비

`spawn-blueprint.json`에 원본 타로스의 **226개 위치**를 원래 좌표/높이/방향과 함께 저장했다. 원본 그룹별 수는 34번 58곳, 37번 23곳, 38번 39곳, 44번 바포메트 106곳이다. 기존 네이티브 로더는 위치마다 2개 리셋 항목을 만들며 0/200/300/400/500/600 변형을 고른다.

`custom-monsters.json`의 명시적 매핑으로 커스텀 몬스터만 연결한다. 현재 44번 바포메트 위치 106곳에 80번 **태초의 바포메트**를 연결했으며, 다른 120개 위치는 `custom_mob: null`로 대기 중이다. 새 맵의 리셋 항목은 212개이며 원본 몬스터는 섞이지 않는다. 기존 타로스의 실제 배치 452개 리셋 항목은 그대로다. 복사된 마을 NPC와 이동 상인은 제외했다.

재생성:

```powershell
runtime/python/python.exe -B -X utf8 tools/build_forgotten_taros.py --server <기존-server-local/LAQIA_GameServer> --client <기존-GameClient>
```

빌더는 `custom-monsters.json`에 등록된 그룹만 활성화한다. 새 커스텀 종류를 추가하면 이 매핑을 갱신하고 재생성한다.

## 업데이트와 검증

정적 서버 데이터는 `DATA/LocalWorld_*.map`, `DATA/LocalWorld_*.txt`로 배포한다. 새 서버의 `--wrap=fopen`은 읽기 전용 `./MAP/` 파일 요청에서 해당 DATA 파일이 있을 때만 대체 파일을 연다. 원래 MAP 파일과 모든 기존 맵의 네이티브 배치 보정 코드는 유지한다. 이전 아버지용 업데이트 프로그램의 DATA 허용 형식과 호환되며 DB/계정/세이브는 포함하지 않는다.

클라이언트와 서버의 맵 이름 파서를 공백을 포함한 최대 63바이트로 읽도록 수정하여 `잊혀진 타로스` 전체 이름을 보존했다.

`live-validation.json`: 기존 32개 맵의 배치 수, 새 맵 이름/빈 스폰, 실제 포탈 이동 패킷, 왕복 방지, 지옥마 속도와 재접속, 새 맵 내 재접속을 검증했다. 기존 계정·캐릭터 관련 5개 저장 테이블의 전체 해시가 검사 전후 일치한다. 원래 출력 폴더 설치본에 적용했으며 임시 테스트 캐릭터는 삭제했다. 네이티브 게임 창을 통한 화면 검수는 별도다.

## 기존 몬스터 스탯

`monster-stats.json`은 파일 추정치가 아닌 실행 중인 서버의 실제 값이다.

| 몬스터 | ID | 실제 레벨 | HP | 공격력 | 방어 | 마법방어 |
|---|---:|---:|---:|---:|---:|---:|
| 바포메트 기본 | 44 | 161 | 2,315 | 679~781 | 147 | 189 |
| B.바포메트 | 644 | 175 | 4,670 | 1,374~1,578 | 302 | 386 |
| 바포메트 워리어 기본 | 53 | 176 | 6,434 | 848~957 | 189 | 268 |
| B.바포메트 워리어 | 653 | 190 | 12,924 | 1,704~1,922 | 386 | 544 |

일반 바포메트 변형은 실제 레벨 161~165, HP 2,315~2,335, 최소공격 679~687/최대공격 781~789다. 일반 워리어 변형은 실제 레벨 176~180, HP 6,434~6,462, 최소공격 848~852/최대공격 957~961이다. 워리어의 화면 이름은 L191~L195이지만 실제 레벨 필드는 176~180이다. 이 불일치는 기존 데이터이며 이번에 바꾸지 않았다.

참고: 원본 보스 경험치 파일 값 91,453 / 100,778은 기존 WORD 필드에 들어가므로 실행 서버 값은 25,917 / 35,242다. 이번 몬스터 조회 보고서는 실행값을 기록하며 경험치 설정을 변경하지 않았다.
