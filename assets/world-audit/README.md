# 몬스터 미배치 맵 조사 · 2026-09-22

## 비어 있는 필드 직전의 몬스터

| 진입 동선 | 직전 맵 몬스터 (실제 일반 레벨) |

| 바이곤(31) → 바터스케어(20) | 트렌트 211~215, 그리폰 241~245, 고쿤 236~240 |

다크홀 바로 이전의 마쉬랜드(32): 덤프솔져 246~250, 덤프솔져워리어 251~255, 고쿤 236~240

이름 앞 숫자와 MOB_DATA의 실제 레벨이 다른 몬스터가 있다. 예를 들어 P310.구울의 실제 일반 레벨은 256부터이며 P360.가스트는 261부터다. 위 표는 실제 레벨 필드를 사용한다. 보스 변종은 JSON의 possible_variants에 별도로 기록했다.

배치점 수는 현재 살아 있는 개체 수가 아니다. 원본 로더는 배치당 두 번 리젠 항목을 만들며 일부 맵에는 추가 리젠이 있다. 비어 있는 맵 여부는 실행 중인 서버의 mobResetCnt와 currMobCnt로 재확인했다. 이벤트 보스는 기존 리젠 항목을 사용하는 바크난(10)·수헤르(11)·모자드(12)에 해당하며 위 빈 맵에는 해당하지 않는다.

원본 맵·몬스터·이동속도·DB는 변경하지 않았다. 검사 뒤 이번 확인을 위해 시작한 VM은 정상 종료했다.
