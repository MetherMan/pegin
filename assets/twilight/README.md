## 색상과 아이콘

사용자 설정 #294AE0, 채도 186%, 밝기 86%, 금속 #FFFFFF, 거칠기 100%를 유지했습니다. `game_appearance.json`은 게임 텍스처에 구워지는 설정입니다. 미리보기에서 추가로 조절한 값은 자동으로 게임에 반영되지 않습니다.

인벤토리 아이콘은 내장 ImageGen으로 새 디자인의 칼날을 크게 담아 검은 배경·금색 테두리로 제작했습니다. 손잡이 끝은 넣지 않았습니다. `build_icon.py`가 원본을 게임용 28×28 WTM으로 인코딩합니다.

## 재생성과 검증

`trace_design04.py`는 원본 이미지 픽셀을 수정하지 않고 형상의 벡터 윤곽을 추출합니다. 결과는 `design04_geometry.json`에 저장되어 있습니다. Node로 `build_model.mjs`, NumPy/Pillow Python으로 `convert_native.py`와 `build_icon.py`를 실행합니다. 저장소의 `tools/build_twilight.py`가 모델·텍스처·아이콘을 client-overlay로 함께 갱신합니다.

`verify_design04.py`는 실제 MOD에 대해 구멍의 관통 여부, 추가 칼날의 실체, 전체 길이, 세 LOD와 28픽셀 아이콘을 검사합니다. `verify_native_animation.py --client <GameClient 폴더>`는 원래 무기 대기 애니메이션의 메시 연결을 검사합니다. 정면·뒷면·옆면 미리보기 검수 완료. 실제 게임 화면에서의 확인은 별도입니다.

과거 `live_validation.json` 등은 이전 등록/강화 검사 기록이며 이번 디자인의 새 검사는 `design04_validation.json`에 있습니다.

게임에서 날 방향을 반대로 향하도록 native X(손잡이→검끝) 축으로 180도 회전합니다. `native_orientation.json`에 저장되어 재빌드에도 유지됩니다. 길이와 잡는 위치, UV는 동일하며 `edge_direction_validation.json`에서 이전 모델 대비 모든 삼각형의 좌표·노멀 회전을 검증했습니다.
