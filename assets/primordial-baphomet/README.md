# 태초의 바포메트

- Lv.231 / HP 23,162 / 공격력 1,470~1,610.
- 기존 기본 바포메트(ID 44)의 `Monster/p-warrior.mod`를 별도 모델로 복제했다.
- 크기 1.4배. 메시뿐 아니라 모든 본의 기준 위치와 8개 애니메이션의 이동 좌표도 같은 비율로 확대했다. 본 회전, 애니메이션 프레임 수, 스키닝 인덱스, 삼각형 연결 구조와 원본 사운드는 유지한다.
- 어두운 몸체에 핏자국, 손끝과 발끝의 짙은 붉은 착색, 칼끝의 붉은 그라데이션. 텍스처는 원본 아틀라스를 ImageGen으로 편집한 별도 파일이다.
- 몸체 UV는 원본 그대로다. 칼은 ImageGen 결과물의 흰 좌우 여백을 샘플링하지 않도록 UV의 U를 실제 아틀라스 영역으로 대응시켰다. 창의적으로 텍스처를 다시 그리거나 원본 바포메트 텍스처를 교체하지 않았다.

## 모델과 미리보기

`index.html`은 게임에 들어가는 실제 모델·텍스처와 원본 본 행렬을 읽는 애니메이션 미리보기다. 원본/신규/같은 카메라의 크기 비교, 대기/걷기/달리기/공격, 회전·확대·정지가 가능하다.

미리보기 주소: `http://127.0.0.1:8877/assets/primordial-baphomet/` (저장소 루트의 로컬 HTTP 서버).

845개 정점, 1,650개 삼각형, 29개 본. 파싱·전체 모션 확대 검증은 `validation.json`, 실행 서버의 실제 스탯과 스폰 조회는 `live-validation.json`에 있다. 텍스처 생성 프롬프트와 원본/생성 이미지도 이 폴더에 보관한다.

## 등록과 배치

새 기본 번호는 80이다. 기존 맵 로더의 변형 선택 방식에 맞춰 280/380/480/580/680도 같은 이름·외형·스탯으로 등록했다. 클라이언트 동작 테이블은 이 번호들을 80으로 해석하여 신규 모션을 사용한다. 원본 몬스터의 테이블 항목과 모션은 그대로다.

방어력 147, 마법방어 189, MP 456, 공격 범위 3, 드롭 목록은 기본 바포메트에서 유지했다. 경험치는 사용자 요청에 따라 기본 바포메트워리어(ID 53)의 15,044보다 약 10% 높은 16,548로 설정했다. 기존 보스 변형의 강화 스탯·보스 드롭을 새 변형에 섞지 않았다.

잊혀진 타로스의 원본 바포메트 배치 106곳을 연결했다 (`../forgotten-taros/custom-monsters.json`: 44 → 80). 네이티브 방식대로 212개 리셋 항목을 만든다. 다른 몬스터 그룹의 준비된 위치는 계속 비활성이다. 실제 살아 있는 몬스터 수도 새 종류만 존재함을 확인했다.

전체 모델 재생성: `runtime/python/python.exe -B -X utf8 tools/build_primordial_baphomet.py` 후 `build_forgotten_taros.py`로 맵 표식을 갱신한다. `skin-settings.json`이 있으면 저장한 `body-atlas.png`를 사용해 피부색을 보존한다. 최초 모델 버전 `2026-09-22-primordial-baphomet`은 회사 PC의 원래 outputs 실행본에 적용해 검증한 기록이다.

## 2026-09-22 붉은 뿔·세 눈과 피부색 조절

내장 ImageGen으로 기존 몸체 UV 아틀라스의 뿔과 세 눈을 붉게 편집했다. 생성 원본은 `body-red-features-imagegen.png`, 정확한 프롬프트는 `red-features-prompt.json`에 보관한다. 메시와 UV, 애니메이션, 칼, 서버 스탯은 변경하지 않았다.

`client-overlay/Tools/BaphometColors/Open.cmd`에서 원본 모션을 보며 피부 색조·강도·밝기를 조절하고 **피부색 저장**을 누른다. **기본 피부색**은 붉은 뿔·눈이 있는 기본 피부색을 불러오며, 저장해야 실제 파일에 반영된다. 뿔·눈 영역과 붉은 핏자국은 색조와 밝기 변경으로부터 보호한다.

사용자가 최종 저장한 값은 **#323539 / 강도 75% / 밝기 1.00배**다. 현재 값의 원본은 `skin-settings.json`이며, 재생성 기준 아틀라스와 저장 아틀라스를 분리해 반복 저장 시 색이 누적되지 않는다.

저장소에서 저장하면 `body-atlas.png`, `skin-settings.json`, 배포 WTM, 편집기 설정 및 manifest 해시가 함께 갱신된다. 백업은 저장소의 `.local/baphomet-color-backups`에 둔다. 설치본에서 직접 저장하면 그 설치본의 텍스처만 변경하고 `Tools/BaphometColors/backups`에 백업한다. 게임 실행 중에는 저장을 거부한다.

피부색 도구/텍스처 재생성: `runtime/python/python.exe -B -X utf8 tools/build_baphomet_colors.py`. `--initialize`는 선택한 피부색을 기본값으로 되돌리므로 최초 준비 때만 사용한다. 이후 `tools/package_father_update.py --manifest-only --version 2026-09-22-baphomet-red-skin-exp`로 배포 목록을 갱신한다.

아버지는 커밋·푸시된 파일을 기존 자동업데이트로 받고 원래 outputs의 **혼자 게임 시작**을 사용한다. 집 PC에서 확인하지 못한 설치 경로에 새 게임 실행기를 만들지 않았다. 이번 색상 변경은 브라우저 미리보기·저장과 게임 텍스처 파일을 검증했으며 실제 outputs 게임 화면 검수는 하지 않았다.

검증: `runtime/python/python.exe -B -X utf8 tests/baphomet_colors_test.py`. 저장 결과와 편집기 계산의 픽셀 일치, WTM/BMP/PNG 일치, 붉은 영역 보호, 저장 실패 롤백, 실행 중 저장 차단, manifest 갱신을 확인했다. 결과는 `skin-validation.json`.

## 경험치 비교

`game-data/DATA/MOB_DATA.txt`의 기본 경험치 기준이다. 실제 획득치는 서버 배율·캐릭터 레벨·파티 등의 영향을 받을 수 있다. 사용자 요청으로 태초의 바포메트와 모든 변형의 경험치를 14,328에서 16,548로 변경했다.

| 종류 | ID | HP | 기본 경험치 |
|---|---:|---:|---:|
| 기본 바포메트 | 44 | 2,315 | 14,328 |
| 기본 바포메트워리어 | 53 | 6,434 | 15,044 |
| 태초의 바포메트 | 80 및 280~680 변형 | 23,162 | 16,548 |
| B.바포메트 | 644 | 4,670 | 91,453 |
| B.바포메트워리어 | 653 | 12,924 | 100,778 |

태초의 바포메트 경험치는 기본 워리어 15,044 × 1.10 = 16,548.4를 정수로 반올림한 16,548이다. 여섯 변형 모두 동일하며, 서버 테이블과 클라이언트 압축 테이블 및 재생성 도구에 반영했다. 검증 기록은 `experience-validation.json`이다. `live-validation.json`은 회사에서 변경 전 경험치 14,328을 확인한 과거 기록이며 이번 경험치 변경의 실행 검증으로 사용하지 않는다. 일반 변형의 경험치는 바포메트 14,328~14,456, 워리어 15,044~15,108이다. 워리어의 이름 접두사는 L191이지만 실제 레벨 열은 176이며, 비교에는 이름이 아닌 데이터 열을 사용했다. 전체 비교 데이터와 원본 해시는 `experience-comparison.json`에 있다.
