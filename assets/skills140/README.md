## 2026-09-22 인게임 이펙트 로딩 오류와 스킬 아이콘 수정

실제 outputs 설치본 errlog의 Magic Part → Magic Effect → 잘못된 스크립트 오류를 추적했다. 구형 `W3DMagic.cpp::ReadEffect`는 빈 줄을 읽으면 직전 키워드를 유지한다. 새 스크립트의 `[/PART]` 다음 빈 줄이 중첩 ReadPart를 다시 호출해 파일 끝까지 소비했다. 기존 태그 개수 검사와 브라우저 미리보기는 이 오류를 잡지 못했다. generator에서 빈 줄 없이 네이티브 스크립트를 내보내도록 수정했다. `Character::AddMagic`은 AddMagic 성공 시에만 MagicCasting을 호출하므로 B 스크립트 로딩 실패는 마법 모션 누락과도 연결된다.

`tools/verify_magic_loader.py`는 Windows CRT sscanf와 기존 파서의 중첩/키워드 보존 규칙을 사용한다. 수정 전 5개 파일(아처 3변형, 마법 B 2개)의 EOF 오류를 재현했고, 수정 후 모든 트와일라잇 스크립트의 EFFECT/PART/BLOWTIMING 수가 일치한다. 이 검사는 그래픽 클라이언트 자체를 실행한 테스트는 아니다. 실제 전투 화면 재검수는 아직 하지 않았다.
