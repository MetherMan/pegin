# 이펙트 색상과 기존 게임 그림체에 맞춘 조정

현재 적용 예외: 사용자의 후속 요청으로 식스폴드 샷은 [이전 붉은 배경 버전](../painted-v4/six-source.png)을 사용한다. 아래 색 기준과 이 폴더의 식스폴드 원본은 v5 제작 당시 기록이며, 현재 빌드는 `ART_OVERRIDES`로 painted-v4를 선택한다. 묶음 미리보기에도 롤백한 아이콘을 반영했다.

내장 ImageGen 편집으로 painted-v4의 구도와 공격 방향을 유지하며, 세밀한 금속·불꽃·얼음 묘사를 줄이고 넓은 명암 면과 선명한 실루엣으로 조정했다. 기존 아이콘 계열은 그림체 참고로만 사용한다.

| 스킬 | 이펙트 기준색 | 확인한 원본 |
| --- | --- | --- |
| 헤븐 페너트레이션 | `#72DFFF` 청백색 | `mh_ps0002_1.wed`의 31프레임 색 |
| 식스폴드 샷 | `#73CCFF` 청백색 | 트와일라잇 활 `mt_arrow.wed`의 31프레임 색 |
| 메테오 버스트 | `#D65C5C` 붉은색 | 사용자가 저장한 meteor 색 |
| 트라이스파이크 프로스트 | `#862882` 보라색 | 사용자가 저장한 frost 색 |

아이콘은 이 색들을 중간톤의 기준으로 사용하며 명암과 하이라이트를 포함한다. 식스폴드 아이콘은 트와일라잇 활 기준이고, 일반 활의 실제 스킬 이펙트는 기존 흰색이다. 스킬 이펙트 색상을 나중에 변경해도 아이콘이 자동 재생성되지는 않는다.

현재 빌드는 이 버전을 사용한다. 실제 outputs 설치본의 아이콘 WTM 8개만 백업 후 교체했고 자산 검사 및 전체 클라이언트 135개 해시가 일치했다. 버전 `2026-09-22-skill-icons-effect-matched`; 설치 기록 `../../effect-matched-icons-installation.json`. 서버/DB/스킬 이펙트는 수정하지 않았다. 실제 게임 화면 검수 및 commit/push는 하지 않았다.
