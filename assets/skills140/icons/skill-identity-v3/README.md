# 스킬 이름과 동작을 중심으로 재구성한 아이콘

기존 아이콘의 그림체와 색 사용을 참고하되, 원본 사물이나 구도를 반드시 남기지 않는다. 단순 복제·추가 대신 새 스킬의 공격을 한 장으로 표현한다.

| 스킬 | 읽혀야 하는 동작 | 이어가는 시각적 특징 |
| --- | --- | --- |
| 헤븐 페너트레이션 | 세 번의 청색 관통 공격이 집중되어 범위 타격 | 패너트레이션 계열의 은빛/청색 날, 보라색 공간, 강한 흰색 명암 |
| 식스폴드 샷 | 여섯 화살의 빠른 연속 발사 | 더블샷 계열의 분홍빛 은색 화살과 붉은 주황색 대비 |
| 메테오 버스트 | 공중 마법진에서 쏟아지는 일곱 포탄 | 흑마법 불덩이의 흰 중심, 붉은 테두리, 검은 여백 |
| 트라이스파이크 프로스트 | 전방과 좌우 45도로 퍼지는 세 갈래 얼음 공격 | 스파이크아이스 계열의 청백색 면, 날카로운 얼음 명암 |

내장 ImageGen으로 기존 계열의 이미지 세 장을 스타일 참고로 전달했다. 입력은 `*-family-reference.png`, 생성 원본은 `*-source.png`, 게임용 이미지는 `*-28.png`이며 정확한 프롬프트는 `prompts.json`이다. `original-to-upgraded.png`는 기존 계열과 새 구성의 비교용이다.

아이콘은 28×28로 가져와 기존 금테두리를 적용하고 Item/Texture/Body의 WTM으로 저장한다. 저장한 스킬 이펙트 색상과 아이콘 그림의 색상은 독립적이다.
