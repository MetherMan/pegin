# 스킬 일러스트 재생성

내장 ImageGen으로 손으로 그린 질감의 스킬 일러스트 네 장을 새로 생성했다. 기존 계열의 팔레트를 참고하며 스킬 동작을 중심으로 새 구도를 구성했다.

- [헤븐 페너트레이션](heaven-source.png): 세 관통 화살과 집중 충격.
- [식스폴드 샷](six-source.png): 여섯 발의 연속 화살.
- [메테오 버스트](meteor-source.png): 공중 마법진과 일곱 포탄.
- [트라이스파이크 프로스트](frost-source.png): 세 갈래 얼음 공격.
- [원본 일러스트와 실제 28px 아이콘](art-and-native-preview.png)
- [정확한 생성 프롬프트](prompts.json)

게임용 28px 변환 후 원본 금테두리를 적용했다. 생성 일러스트와 게임 아이콘의 해상도는 다르며 비교 이미지 아래에 실제 크기를 표시했다. 빌드 도구는 이 버전을 사용한다.

기존 outputs 설치본의 아이콘 WTM 8개만 백업 후 교체. 자산 검사 및 클라이언트 135개 해시 일치. 버전 `2026-09-22-skill-icons-painted`; 설치 기록 `../../painted-icons-installation.json`. 게임 화면 검수 및 commit/push는 하지 않았다.
