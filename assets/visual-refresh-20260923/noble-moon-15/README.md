# 푸른달의 트와일라잇 · 15개 ImageGen 시안

2026-09-23 사용자 요청에 따라 검·활·지팡이를 각각 5개씩 새로 생성했다. 15장 모두 개별 ImageGen 호출로 만든 1024×1536 원본이며, 이번 시안으로 모델을 제작하거나 설치본을 교체하지 않았다.

[비교 갤러리](index.html)는 종류별 필터, 원본 확대, 같은 종류의 이전·다음 시안, 종류별 선택과 선택 요약 복사를 제공한다. 선택은 브라우저 로컬 저장소의 비교 표시만 바꾼다. 전체 미리보기는 [gallery-overview.png](gallery-overview.png)다.

| 종류 | 번호 | 시안 |
|---|---|---|
| 검 | S1–S5 | 초승달 궁정 / 쌍월의 날개 / 성월의 궤도 / 달빛 물결 / 월식의 왕관 |
| 활 | B1–B5 | 초승달 궁정 / 쌍월의 날개 / 성월 관측궁 / 달빛 물결 / 월식의 왕관 |
| 지팡이 | T1–T5 | 만월 성소 / 삼중 월관 / 성월 관측의 / 달빛 꽃 / 월식 왕홀 |

정확한 생성 프롬프트와 생성 원본 경로는 [검](sword-prompts.json), [활](bow-prompts.json), [지팡이](staff-prompts.json)에 보존했다. [manifest.json](manifest.json)은 이미지와 프롬프트 연결, 크기, SHA-256을 기록한다.

[asset-validation.json](asset-validation.json): 15장 PNG 구조·CRC·크기·서로 다른 해시·ImageGen 원본과 복사본 일치·프롬프트 연결 모두 통과. 기존 보호 파일 59개와 두 설치 경로의 검·활 리소스 16개는 이전 기준 해시와 동일하다. 이 비교는 DB 내용이나 실행 중 게임 화면 검사에 해당하지 않는다.

브라우저에서 15장 전체 표시, 활/지팡이 필터, T5 확대와 T1 순환, 선택·해제를 확인했다. 콘솔 오류는 관찰되지 않았다. 새 시안의 실제 인게임 가독성은 모델 제작 후 확인해야 한다.
