# 뿔 형태 푸른달 활 10종

A04의 갈라진 월뿔과 V01의 휘감긴 상현 월뿔을 실제 참조 이미지로 전달하여 내장 ImageGen으로 10장을 각각 생성했다. 청색 결정으로 된 휘고 갈라지는 뿔을 중심으로, 상하 비대칭과 작은 달 상징을 유지했다. 각 장에는 활 하나만 담았으며 1024×1536 생성 원본의 바이트를 그대로 보존했다.

[확대·선택·다운로드 갤러리](index.html) · [통합 프롬프트·참조·원본 기록](prompts.json) · [파일 검증](asset-validation.json)

갤러리에서 번호별로 확대하거나 원본 크기로 스크롤할 수 있고, 각 PNG를 다운로드할 수 있다. 선택 상태는 이 갤러리 전용 브라우저 저장 키를 사용한다.

10개 원본의 동일 바이트, 서로 다른 SHA-256, 1024×1536 규격, 실제 두 참조 경로 및 개별 육안 검수 기록을 확인했다. 모든 활과 뿔 끝은 보이지만 생성 결과의 상하 여백은 요청한 7%보다 좁다. 일부 뿔은 둥근 단면보다 결정 면이 강조됐다. 상세 차이는 각 visual_qa에 남겼다.

디자인 비교용 이미지 갤러리이며 게임 모델·스킬·설치본·실행 경로 변경은 포함하지 않는다.
