# 푸른달의 트와일라잇 · 비대칭 활 시안 10장

한 이미지에 활 하나만 담는 요청에 따라 내장 ImageGen을 10회 독립 호출해 새로 생성했다. 모든 원본은 1024×1536 세로 이미지이며 이전 3개짜리 시안의 잘라내기·확대본이 아니다. 생성 후 이미지 편집 없이 원본 바이트를 보존했다.
