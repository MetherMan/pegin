# 2026-09-23 v6 · 연쇄 빙결·눈보라·폭풍 폭발·푸른달 문양

정갈한 동심원 분출을 불규칙하고 빠른 연쇄 분출로 바꾸고, 메테오 착탄과 마지막 폭발을 강화했다. 검·활은 승인한 디자인을 유지하며 달 문양과 칼날을 보강했다. 이 문서는 제작 기록이며 사용자의 별도 지시를 대신하지 않는다.

## 확인할 화면

- [스킬 미리보기](http://127.0.0.1:8878/): 단계별 정지와 확대 보기 제공.
- [무기 거리·배경 비교](http://127.0.0.1:8876/assets/twilight-set/readability.html): 실제 MOD/WTM을 원본 캐릭터에 부착하여 축소 화면의 달 문양 확인.
- 두 화면은 네이티브 자산을 읽은 브라우저 재현이다. 실제 Direct3D 게임 캡처나 성능 측정은 아니다.

## 변경 내용

**코시투스:** 63개 얼음이 불규칙한 9개 경로를 따라 외곽부터 안쪽으로 연속 분출한다. 뿌리는 지면에 고정되고 간격·크기·기울기는 서로 다르다. 저장 설정 기준 약 129~1,047ms에 연쇄 분출한 뒤, 마법진과 함께 약 1,244ms에 중앙 기둥이 나타나 약 107ms 동안 급상승한다. 후속 분출 16개, 주변 가시 11개, 날리는 빙편 18개, 눈발 288개와 불완전한 바람 띠 4개를 더했다. 바닥의 얼음 지대 잔상은 유지한다.

**메테오:** 각 포탄의 도착에 맞춰 중심 화염·불꽃 확산·압력파의 3층 착탄이 발생한다. 마지막 거대 화염탄은 더 큰 중심 폭발과 함께 18개의 화염 전선을 바깥으로 밀어낸다. 원본 압력파와 불씨 띠, 뜨거운 파편 8개가 이어지고 회오리·마그마 잔열이 남는다. 보조 연출은 피해 이벤트를 추가하지 않으며 메테오 7회·코시투스 3회와 서버 범위를 유지한다.

**무기:** 검의 초승달은 15%, 활의 초승달은 20% 키우고 청색 경사를 둘러 은빛 장식에서 분리했다. 검은 긴 경사면과 얇은 날끝을 만들고 끝으로 갈수록 두께·폭을 줄였다. 실제 MOD 측정상 주 칼날 전체 두께는 0.04431236에서 끝 부근 0.01395191로 줄어든다. 검·활의 원화 영역을 각각 전용 UV 타일에 배치했다. 지팡이는 동일 바이트를 유지한다. [무기 상세 검증](../twilight-set/MOON-REFINEMENT-REVIEW.md).

## 검증·설치 상태

- `verify_skill_tuning.py`: 20개 조절값 및 설정 범위 검사 통과.
- `verify_skill140_assets.py`와 네이티브 로더 검사 통과. `verify_skill_preview.py`: 실제 텍스처 12,558,336개 픽셀 일치.
- 무기 MOD 측정·폐곡면·UV/재질·42개 아이템 연결 검사 통과.
- 최종 연쇄 분출·중앙 기둥·눈보라와 메테오 장면을 브라우저에서 확인했으며 콘솔 오류는 없었다. 무기 설치 16파일 해시 재확인 및 manifest `2026-09-23-stormburst-blue-moon-preview`의 일반 605개·런타임 3개, 총 608개 해시 검증 통과. manifest 갱신은 기존 설치본에 스킬을 적용한 것을 뜻하지 않는다.
- 검·활 8파일을 기존 아버지 설치본과 저장소 런타임에 각각 적용했다. 총 16파일 설치 및 보호 파일 36개 해시 동일. [설치 기록](../twilight-set/moon-refinement-installation.json)의 백업은 `moon-refinement-20260923-133842`다.
- **스킬은 미리보기용이며 기존 게임 설치본에는 이번 변경을 적용하지 않았다.** DB·VM·계정·실행 CMD는 변경하지 않았다. 실제 전투의 Direct3D 표시·성능 검수와 원격 push는 수행하지 않았다.
- 이번 작업은 새 ImageGen 생성 없이 기존 원화·텍스처와 네이티브 형상·동작을 수정했다. 자동 검사 통과는 미적 만족도나 실전 성능을 보장하지 않는다.
