# 푸른달 무기·스킬 조절 패널 v7 · 2026-09-23

기존에 저장한 20개 조절값과 색상을 보존하고 조절 항목을 총 56개로 늘렸다. 새 배율은 1, 위치 보정은 0으로 시작한다. 스킬은 **미리보기 전용**이며 이번 스킬 변경을 기존 게임 설치본에 적용하지 않았다. 무기 설치 상태·백업·보호 파일 해시는 [noble-moon-installation.json](../twilight-set/noble-moon-installation.json)을 기준으로 확인한다.

최종 검·활은 원화 픽셀 패킹과 캐릭터 장착 화면을 확인한 뒤 기존 아버지 설치본과 저장소 런타임에 각각 8파일씩, 총 16파일을 반영했다. 백업은 기존 설치의 `work/laqia-runtime/backups/noble-blue-moon-20260923-141001`이다. 실행기·설정·표·지팡이·설치된 스킬 59파일이 작업 전과 동일하다.

## 미리보기 사용

1. [스킬 패널](http://127.0.0.1:8878/)에서 확인할 스킬의 **확대 보기**와 단계별 버튼을 선택한다.
2. 화면 아래의 접기 그룹을 펼쳐 광량·진하기·크기·위치·속도를 조절한다. 일시정지한 장면에서도 값이 반영된다.
3. **미리보기 설정 저장**을 누르면 다음에 열어도 유지된다. **이 스킬 추천값**은 해당 스킬의 수치만 복원한다.

광량은 빛의 세기, 진하기는 보조층과 잔광의 비중이다. 메테오는 일반·최종 화염탄 크기와 속도, 착탄·최종 폭발 크기, 두 마법진의 크기·높이·좌우·앞뒤·분산을 조절한다. 얼음은 하·중·상단 마법진 높이와 위치, 눈보라의 실제 입자 수와 바람 강도를 조절한다. 아처는 화살·활 앞 발사 폭발·적중 폭발과 높이, 헤븐의 범위 연출을 조절한다. 피해 횟수와 서버 범위는 바뀌지 않는다.

실시간 반영 때 새 WEM 기하와 WTM 텍스처까지 다시 읽도록 수정했다. 따라서 눈보라 밀도·마법진 기울기 등도 저장될 실제 네이티브 자산과 같은 방식으로 바뀐다. `/save-preview`는 제작용 `client-overlay`만 기록하며 설치본 복사 경로를 사용하지 않는다. 미리보기 모드의 `/apply`는 403으로 차단한다. 브라우저에서 1 → 1.5로 변경·저장·새로고침 유지까지 확인한 뒤 1로 복원해 저장했다.

헤븐은 각 화살의 실제 도착에 청색 파열·룬 테두리·지면 파동·빛 파편을 연결했다. 식스폴드는 기존 흰색/파랑 변형을 유지한다. 아처에도 `활 앞 발사`, `첫 적중`, `범위 파열` 또는 `연속 적중` 정지 버튼을 추가했다. 헤븐 광량 1→0.55→1, 식스폴드 적중 크기 1→1.5→1을 브라우저에서 반영하고 복원했으며 콘솔 오류는 없었다.
