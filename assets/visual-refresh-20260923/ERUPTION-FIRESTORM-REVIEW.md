# 2026-09-23 지면 분출 코시투스 · 메테오 재검수

이번 후속 요청의 핵심은 얼음 조각 이동이 아니라 **지면이 바깥부터 안쪽으로 차례로 솟는 연출**이다. 직전 v4의 안쪽 이동 경로를 대체했다. 이 문서는 제작 기록이며 사용자의 별도 지시를 대신하지 않는다.

## 확인할 화면

- [스킬 미리보기](http://127.0.0.1:8878/): `외곽 솟음 → 중앙으로 전개 → 거대 기둥 → 얼음 지대`, `8진 포격 → 최종 마법진 → 거대 화염탄 → 화염 회오리 → 마그마 잔열` 버튼으로 정지 장면 확인.
- [무기 화면 크기 비교](http://127.0.0.1:8876/assets/twilight-set/readability.html): 실제 MOD/WTM과 캐릭터를 같은 비율로 표시. 90/140/240px 비교용 거리와 배경 명도, 회전 선택.
- 두 화면 모두 브라우저 재현이며 실제 Direct3D 전투 캡처가 아니다. 캐릭터 화면 높이는 비교용 기준이고 실제 게임 카메라 설정값을 뜻하지 않는다.

## 변경 내용

코시투스: 5개 반경의 고정된 지면 위치에서 50개 수정이 외곽부터 안쪽으로 솟는다. 저장된 설정 기준 0.10/0.40/0.70/1.00/1.30초 순서이며 중앙 기둥은 1.82초에 시작한다. 기둥은 실제 캐릭터보다 훨씬 높고 굵은 단일 다면체와 기울어진 주변 가시 10개로 구성했다. 기존 얼음 텍스처의 청색을 유지하고 저장된 보라색은 보조 마법진에 사용한다. 추가 분출 18개가 후반까지 이어진다. 바닥은 외곽부터 안쪽으로 얼어붙고 기둥 소멸 후 1.6초 더 남아 천천히 사라진다. 3회 피해·서버 범위 6 유지.

메테오: 8개의 서로 다른 위치와 기울기에서 교차 포격한다. 마법진 법선을 실제 포탄 궤도에 맞췄고, 각 마법진은 발사 후 순차적으로 사라진다. 3개 층에는 기존 게임의 룬 고리/주문진/중앙 문양을 각각 재사용한다. 마지막 거대 마법진과 원본 대형 파이어볼을 유지하고, 원통형 착탄 대신 기존 `d_flame`의 16프레임 화염을 사용한다. 회오리는 기존 Hell의 `fire_03` 애니메이션과 `firewall` 표면을 나선형 공간에 배치해 연속된 불기둥으로 만들었다. 도착 시점에 맞춰 회오리 6개와 마그마 잔열이 이어진다. 7회 피해·서버 범위 6 유지.

무기: 승인한 모델을 변경하지 않았다. 축소 화면에서는 은색이 먼저 보이고 작은 달 문양은 잘 읽히지 않는다. 푸른달의 인상을 충분히 전달한다고 확정할 수 없으며, 큰 초승달 실루엣과 청색 경계의 가독성을 비교하도록 별도 화면을 추가했다. 실제 게임 조명·기존 장비 발광까지 포함한 검수는 남아 있다. 기존 설치본과 저장소 런타임의 무기 24파일이 지난 설치 기록의 해시와 동일함을 확인했다.

## 새 이미지

내장 ImageGen으로 생성한 [얼음 지대 원본](cocytus-frozen-ground-imagegen.png), [최종 프롬프트 원문](cocytus-ground-prompt.json). 생성 결과를 프로젝트에 복사하고 크기 및 WTM 포맷만 변환했다. 소비 파일은 `client-overlay/Texture/Effect/mf_frozen_ground.wtm`. 기존 마그마 이미지는 그대로 사용했다. `tools/build_magma_decal.py`로 두 지면 텍스처를 재현한다.

## 검증 및 설치 상태

- `verify_skill_tuning.py`: 20개 조절값과 최소/저장/최대 설정, 고정된 얼음 뿌리·분출 순서·바닥 잔상 수명·포격 방향 일치 검증 통과.
- `verify_skill140_assets.py`: 표/리소스 의존성/피해 7·3회/기존 스크롤 및 아이콘 보존 통과. Windows CRT 기반 네이티브 파서 통과.
- `verify_skill_preview.py`: 11,849,728개 실제 텍스처 픽셀과 캐릭터 모션 재현 검증 통과.
- 로컬 미리보기 화면을 단계별로 확인. 실제 게임 전투 실행은 하지 않았다.
- 스킬은 `client-overlay`와 미리보기에 반영. 기존 아버지 설치본, 실행 CMD, 설정, 계정, DB, VM은 이번 턴에 쓰지 않았다. 원격 push·배포는 하지 않았다.

스킬 이미지와 동작은 위 미리보기에서 사용자 검수가 필요하다. 자동 테스트 통과는 미적 만족도를 보장하지 않는다.
