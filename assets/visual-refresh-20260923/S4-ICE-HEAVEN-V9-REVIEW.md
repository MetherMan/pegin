# 2026-09-23 · S4 검 설치와 얼음·헤븐 미리보기 v9

사용자가 선택한 S4 달빛 물결 검을 실제 모델로 제작해 설치했다. 활과 지팡이는
새 ImageGen 시안 10쌍을 비교하는 단계다. 헤븐과 얼음 연출 변경 및 60개 조절
항목은 제작용 미리보기에만 반영했으며 게임 설치본의 스킬은 유지했다.

## S4 달빛 물결 검

[선택 원화](noble-moon-15/sword-04.png)의 긴 물결 칼날, 열린 초승달과 비대칭
가드를 입체 모델로 옮겼다. 원본 이미지를 수정하지 않고 312×1496 영역을
아틀라스에 1:1로 배치했으며 실제 WTM을 풀어 466,752픽셀 일치를 확인했다.
날 가장자리와 첨단으로 갈수록 두께가 줄고, 기존 손 원점·축·애니메이션 메시·
아이템 번호·능력치·LOD 연결을 유지한다.

아버지 설치본과 작업공간 runtime에 검 MOD 3개와 WTM 1개를 각각 백업 후
교체했다. 총 8개 파일이며 보호 파일 67개의 해시는 동일하다. 활·지팡이,
설치된 스킬, 계정·DB·VM·실행 CMD 및 실행 위치는 변경하지 않았다.
[제작·검수 기록](../twilight-set/s4/README.md),
[제작 검증](../twilight-set/s4/build-validation.json),
[설치·백업 기록](../twilight-set/s4/installation.json)을 참조한다.
이전 무기 설치 기록은 과거 이력으로 보존한다.

실제 MOD/WTM을 다시 읽은 모델의 정면·사선·옆면·뒷면과 캐릭터 손 장착,
140px·240px 표시 크기를 확인했다. [S4 모델](../twilight-set/index.html?weapon=sword)과
[캐릭터 크기 비교](../twilight-set/readability.html)에서 볼 수 있다.
브라우저 재현 검수이며 실제 게임 Direct3D 전투 화면을 검사한 것은 아니다.

## 활·지팡이 10쌍 시안

내장 ImageGen으로 새 원본 10장을 생성했다. 각 장에는 왼쪽 활 1개와 오른쪽
지팡이 1개가 있으며, 푸른 달이 실루엣과 주재료에서 드러나는 서로 다른
구성으로 만들었다. [10쌍 갤러리](moon-pairs-10/index.html)는 확대 보기와
활·지팡이 후보를 각각 선택하는 기능을 제공한다.
[원본 경로·프롬프트·해시·검수 기록](moon-pairs-10/prompts.json)을 함께 보존한다.
이 시안의 활과 지팡이는 아직 모델링하거나 설치하지 않았다.

## 헤븐과 얼음 연출

헤븐 페너트레이션은 대상 발밑의 룬과 바닥 파동을 제거했다. 적중 시 대상
몸통을 중심으로 빛과 파편이 퍼지게 하고, 화살 3발과 피해 3회를 유지한다.

아일랜드 오브 코시투스는 외곽에서 안쪽으로 밀려드는 불규칙한 흐름 8개와
짧게 터지는 파쇄판 45개로 전개한다. 규칙적으로 줄 세운 얼음 대신 여러
방향의 압력이 중앙으로 모이고, 큰 기둥·가시·마법진·눈보라와 얼음 지대가
이어진다. 안으로 흐르는 안개와 잔류 안개도 함께 조절한다. 피해 3회와
서버 공격 범위는 유지한다.

기존 56개 조절값과 저장 색상을 보존하면서 아래 4개를 추가해 총 60개가 됐다.

| 설정 키 | 화면 항목 | 바꾸는 내용 |
| --- | --- | --- |
| `iceDensity` | 얼음 표면 진하기 | 얼음 표면의 색과 명암 강도 |
| `mistAmount` | 얼음 안개량 | 안쪽으로 흐르는 안개와 잔류 안개, 0은 끄기 |
| `inwardStartRadius` | 외곽 시작 반경 | 안쪽 흐름이 시작되는 시각적 거리 |
| `inwardEndRadius` | 안쪽 도착 반경 | 흐름이 모이는 시각적 거리 |

기존 엔진의 ONE/ONE 가산 합성은 진짜 불투명도를 지원하지 않는다.
따라서 `iceDensity`는 배경을 가리는 알파 불투명도가 아닌 표면 진하기이며,
거리 조절도 서버 피해 범위를 바꾸지 않는다. 기존 저장·추천값 복원 기능과
실시간 조절 시 재생 시점·재생/정지 상태를 유지하는 v8 동작을 보존한다.

## 검증과 적용 범위

[통합 검사](../skills140/v9-integration-validation.json)에서 조절 항목 60개,
기존 값 56개와 색상 보존, 헤븐 바닥 레이어 0개, 메테오·식스폴드 리소스
170개 동일을 확인했다. [최종 브라우저 검사](../skills140/v9-browser-validation.json)에서
표면 진하기 0.25↔2, 안개량 0↔3과 안쪽 흐름 거리의 시각적 차이 및 실시간
변경 중 재생 시점 유지를 확인했다. 안개 높이와 광량을 보정한 최종 화면으로
검수했으며 테스트값은 모두 복원했고 QA 중 설정을 저장하지 않았다.
수집된 브라우저 콘솔 오류는 0개다.

[최종 통합 결과](../skills140/final-v9-validation.json)는 보호 파일 67개,
메테오·식스폴드 170개, 기존 저장값 56개와 색상 보존, 설치된 S4 파일 8개
해시 일치 및 시안 10장의 1536×1024 규격과 독립 해시를 확인했다.
manifest는 기존 `2026-09-23-local-growth-card-fix` 버전을 유지한 채 해시만
갱신했으며 일반 663개와 runtime 3개, 총 666개 파일이 일치했다.

스킬 패널은 preview-only이며 이번 스킬 변경은 설치본에 미적용이다.
배포 manifest 해시만 갱신했으며 배포·commit·push는 하지 않았다.
실제 Direct3D 전투와 성능 검수는 별도로 남아 있다.
