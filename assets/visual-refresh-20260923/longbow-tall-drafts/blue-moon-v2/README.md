# 푸른달 장궁 2차 초안

이전 01~03안이 밋밋하다는 사용자 피드백과 ‘블랙나이트 롱보우도 참고해 푸른달 컨셉에 맞게 다시 디자인’ 요청을 반영한 04~06안이다. 기존의 얇고 균일한 활대 대신 넓은 월형 날, 음각과 열린 공간, 겹친 조각의 입체감으로 장식성을 높였다. 위아래 길이와 활의 시위·그립 구조는 유지하는 방향이다.

내장 ImageGen으로 각 이미지를 별도 생성. 전체 프롬프트는 `prompts.json`, 비교 화면은 `index.html`에 있다. 게임 모델에는 적용하지 않은 초안이다.

참고한 로컬 원본은 H03 푸른 활과 `assets/visual-refresh-20260923/knight-reference.html`의 실제 네이티브 모델이다. 정점 배열을 직접 대조해 블랙나이트 양손검(11424, Ws_0081_1.mod)과 화이트헌터 롱보우(11739, Wb_0040_1.mod)를 확인했다. 이들은 다른 장비 이름의 텍스처를 공유하므로 텍스처 이름만으로 모델을 식별하지 않았다. ‘블랙나이트 롱보우’라는 정확한 아이템명은 로컬 데이터와 웹 검색에서 확인하지 못했으므로, 그 무기의 정확한 재현을 주장하지 않는다.
