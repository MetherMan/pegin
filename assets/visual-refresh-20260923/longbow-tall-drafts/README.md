# 길어진 월뿔 장궁 초안

사용자 요청: 현재 활의 위아래 길이를 늘리고, 기존 디자인 느낌은 이어가면서 지팡이처럼 보이는 인상을 줄인 초안 여러 개.

[비교 화면](index.html)

1. `01-long-recurve.png`: 매끄러운 곡선의 장궁.
2. `02-twin-horn-longbow.png`: 위아래 쌍뿔로 기존 장식성을 계승.
3. `03-swept-war-longbow.png`: 작은 손잡이 달 장식과 선명한 활대·시위.

기존 H03 원화 `../bow-horns-10/bow-03.png`를 재질과 그림체 참조로 built-in ImageGen에서 각각 생성했다. 전체 프롬프트는 [prompts.json](prompts.json). 현재는 선택 전 초안이며 게임 모델·장착 크기·아이템 데이터에는 적용하지 않았다.

후속 모델 제작 시 손잡이 장착 원점은 유지하고 위아래 활대 길이를 늘린다. 현재 H03는 26,580개 삼각형이며 네이티브 엔진은 비인덱스 정점 버퍼와 software vertex processing을 사용하므로 실루엣을 유지하면서 내부 면 분할을 줄일 필요가 있다. 새 모델의 실제 길이와 면 수는 초안 선택 후 별도로 검증한다.
