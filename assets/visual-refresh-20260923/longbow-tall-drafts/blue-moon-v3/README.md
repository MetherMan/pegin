# 푸른달 장궁 · 윗뿔 방향 수정

사용자 요청: 윗쪽에서 앞으로 뻗은 뿔 부분만 활처럼 뒤로 휘도록 변경.

기존 blue-moon-v2의 04, 05, 06을 각각 built-in image_gen으로 편집했다. 화면 오른쪽의 활줄 방향으로 상부 뿔을 휘게 하고, 기존 푸른 수정과 금속 장식, 중앙 달, 손잡이, 아래쪽 활대와 구도를 유지하도록 요청했다. 각 원본은 이전 폴더에 보존했다.

디자인 미리보기만 생성했으며 게임 모델에는 적용하지 않았다.

- 04-lunar-sovereign-swept.png: 월왕의 장궁 수정안
- 05-eclipse-knight-swept.png: 월식 기사의 장궁 수정안
- 06-twin-crescent-regalia-swept.png: 쌍월의 장궁 수정안
- prompts.json: 원본 경로와 각 편집 프롬프트 전문
- index.html: 세 가지 수정안 비교 및 이전안 링크
