# 푸른달의 트와일라잇 — 활 30개 시안

내장 ImageGen을 이미지마다 한 번씩, 총 10회 호출해 새로 생성했다. 한 장에 왼쪽·가운데·오른쪽 활 3개씩 총 30개를 담았다. 전부 1536×1024 PNG이며, 생성 원본을 수정하지 않고 그대로 복사했다.

코발트·청금석·투명 청석과 크고 분명한 푸른달을 중심으로 구성했다. 작은 세공의 반복보다 큰 달, 비대칭 팔다리, 넓은 청석 면과 열린 공간을 강조했다. 손잡이와 활줄이 보이며, 지팡이·검·인물·문구 없이 활만 비교할 수 있다.

| 파일 | 방향 | 왼쪽 A | 가운데 B | 오른쪽 C |
|---|---|---|---|---|
| [bows-01.png](bows-01.png) | 거대한 초승달 | 상단 거대 초승달 | 손잡이를 감싼 거대 월호 | 하단 초승달 반전 |
| [bows-02.png](bows-02.png) | 만월의 건축 | 상단 만월의 아치 | 중앙 만월 성소 | 하단 만월 받침 |
| [bows-03.png](bows-03.png) | 쌍월의 간극 | 겹친 두 초승달 | 교차하는 밝고 어두운 월호 | 엇갈린 위아래 쌍월 |
| [bows-04.png](bows-04.png) | 깊은 월식 | 어두운 월식의 테두리 | 중앙 반월의 긴 곡선 | 파쇄된 월식 외곽 |
| [bows-05.png](bows-05.png) | 달빛의 파도 | 상단 파도와 초승달 | 중앙 달빛 파도날 | 하단 달의 물결 |
| [bows-06.png](bows-06.png) | 쇄월의 청석 | 세 조각 상단 월석 | 큰 반월판과 각진 팔 | 엇갈린 하단 월석날 |
| [bows-07.png](bows-07.png) | 고결한 월익 | 초승달을 품은 월익 | 굵은 청석 날개와 만월 | 하단 거대 반월익 |
| [bows-08.png](bows-08.png) | 반달의 왕관 | 상단 반달 왕관 | 중앙 월호의 왕실 활 | 하단 만월 왕관 |
| [bows-09.png](bows-09.png) | 고대 월석 성물 | 굵은 상단 월석 성물 | 층진 청석과 하단 만월 | 열린 눈 모양과 하단 반월 |
| [bows-10.png](bows-10.png) | 오로라 월광 | 상단 달과 오로라 비틀림 | 겹친 월광띠와 하단 만월 | 거대한 상단 월광 돛 |

각 활은 `B01A`~`B10C`로 식별한다. `A/B/C`는 각각 왼쪽/가운데/오른쪽이다.

[prompts.json](prompts.json)에 정확한 영문 프롬프트, 생성 원본 경로, 파일별 SHA256, 규격, 각 활 이름과 육안 검수 기록을 저장했다. 10장 모두 PNG 무결성·원본 바이트 일치·서로 다른 SHA256을 확인했으며 누락이나 생성 실패는 없다.

디자인 선택용 원화이다. 이번 작업에서 게임 모델·스킬·설치본·계정·업데이트 CMD는 변경하지 않았다.
