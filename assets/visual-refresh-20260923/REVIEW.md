# 2026-09-23 연출 개선과 다음 디자인 제안

## 기존 설치본 보존

이 PC의 기존 `https-laqia-co-kr-https-laqia/outputs/혼자 게임 시작.cmd`와 상위 `게임 시작.cmd`를 그대로 사용한다. 개발용 `LAQIA-THE-LEGEND/Play.cmd`로 연결하지 않았다.

기존 설치본에 적용하면서 LoginAccount, LAQIA_GAMEDB, LAQIA_ITEMLOG, LAQIA_CASH, DAUM_BILLING의 데이터 덤프 해시가 적용 전후 동일함을 확인했다. 실행 CMD와 개인 설정 21파일이 동일하고, 서버 3개가 정상 기동했다. 계정이나 VM 디스크를 교체하지 않았다. 검증 기록은 `../skills140/visual-refresh-installation.json`이다.

첨부 복구 ZIP은 서버 시작 전 최신 업데이터로 이어 실행하고 허용된 시작 도구 3개를 먼저 교체하는 구조다. 작업 저장소의 예전 업데이터에는 이 기능이 없어 그대로 배포하면 복구 기능을 되돌릴 수 있었다. 검토한 복구 구조를 반영하고, 부팅 중인 VM은 다시 띄우지 않고 같은 창에서 준비를 기다리도록 수정했다. SSH 연결·인증 대기를 제한하고, 느린 부팅은 최대 10분까지 진행 상황을 출력하며 기다린다. 실패 시 vm-start-diagnostic.txt를 남긴다. WHPX 실패 시 TCG를 사용하는 원래 fallback은 유지한다.

아버지 PC의 진단 로그는 제공되지 않았으므로 당시 첫 두 번 실패의 원인을 단정할 수 없다. 아버지 PC 직접 검사와 GitHub 자동 배포는 수행하지 않았다.

## 적용한 연출

- 태초의 바포메트: 기존 양옆 뿔에 정수리 뿔 두 개를 추가. 몸통 앞뒤 표면 32개 면을 잘라 실제 원형 공동을 만들고 내부 벽과 검은 핏줄 4개를 조형. 칼날을 비대칭 톱니형으로 교체하고 가드에 굽은 돌기 추가. 핏줄은 흘러내리는 형태의 메시이며 액체 시뮬레이션은 아니다. 원래 29개 뼈와 8개 애니메이션 유지.
- 아처: 원본 데쓰패너트레이션/기존 연사 스킬의 발사광을 참고해 활 앞에 준비광과 발사광 추가. 확대해도 발사광 중심 높이는 1.25로 유지. 헤븐 3발과 식스폴드 6발이 서로 다른 높이에 적중. 밝은 청색과 기존 활의 청백색 변형 모두 적용. 피해 횟수·범위·MP·쿨타임 보존.
- 지옥마: 기존 달리기 먼지 호출을 지옥마(type 4)에 한해 불씨로 바꿈. 550ms 잔불이 지나간 위치에 남으며 정지 후 추가 발생 중단. 탈것 유형 분기 7개와 두 모듈 로딩 주소에서 총 14사례 검증. 원래 파티클 59개 레코드는 그대로 보존.
- 아일랜드 오브 코시투스: 스킬 19123 / 내부 키 mt_frost / 기존 습득 정보를 유지하며 이름 변경. 대상 주위 18개 얼음이 바깥에서 안쪽으로 전개되고, 높이·반경·회전이 다른 큰 마법진 3개가 순서대로 생성된 뒤 거대한 중앙 얼음기둥과 충격파 발생. 기존 피해 3회와 범위 6 유지. 저장된 색상 `#862882`, 조절값 유지.

네이티브 스크립트 파서, 리소스 참조, 20개 조절값과 최소/최대, 저장값 마이그레이션, 981만여 개 미리보기 텍스처 픽셀, 서버 시작·기존 DB 보존을 검사했다. 3D 미리보기는 실제 MOD/WED/WTM/ANI 자산을 읽지만 Direct3D 게임 전투 화면 자체를 캡처한 것은 아니다.

## 트와일라잇 무기: 원인과 대안 — 아직 미적용

현재 활과 스태프는 파란 면/은색 테두리의 대비와 작은 별·달 문양에 시각적 무게가 실려 있다. 원화의 앞뒤 투영 UV와 얕은 표면 부조는 정면 확대에서는 섬세하지만, 실제 게임의 축소된 사선 시점에서는 내부 문양이 사라지고 큰 파란 면이 남는다. 밝은 파란색을 더 칠하는 것만으로는 해결이 어렵다는 판단이다. 기존 세트와의 선호 차이는 주관적이며 아래는 현재 자산 구조를 근거로 한 디자인 제안이다.

| 안 | 형태·재질 | 기대 효과 | 비용/주의 |
|---|---|---|---|
| 1. 월식의 핵 — 권장 | 몸체는 흑청색 금속, 날은 청백색. 큰 빈 공간 속에 달의 핵, 굵은 은색 갈비 구조와 1~2개의 강조 문양 | 작은 화면에서도 어두운 몸체→밝은 날→핵의 순서로 읽힘. 시리즈 공통 특징 형성 | 메시와 재질 재작업 필요. 핵 발광은 별도 게임 효과 연결 가능 여부 확인 |
| 2. 파열된 초승달 | 긴 비대칭 날과 깊은 절개, 갈고리형 보조 날. 파란 결정은 절개 부분에만 제한 | 색을 빼도 알아볼 수 있는 공격적인 윤곽 | 기존 우아한 느낌이 크게 달라짐 |
| 3. 달빛 각성 | 현재 형태 유지. 날 끝의 짧은 청백색 잔상, 타격 순간 달 파편, 제한된 맥동 | 기존 확정 외형을 보존하며 사용 중 존재감 강화 | 정지 상태에서의 조형 약점은 남음 |

권장 세트 변형: 양손검은 중앙의 긴 균열과 깊은 가드, 활은 상단의 큰 초승달과 떠 있는 핵, 스태프는 두꺼운 초승달 감옥 안의 구체. 세 무기에 똑같은 파란 도장을 적용하기보다 같은 재질·핵·윤곽 규칙을 공유한다.

## 메테오 버스트: 대안 — 아직 미적용

현재 구현은 같은 파이어볼 7개를 좌우 대칭으로 연성해 같은 대상 높이로 쏜다. 반복되는 포탄과 정렬된 출발점 때문에 운석비보다 마법 탄환 일제사격처럼 읽힌다. 원본 상위 흑마법은 대상 주변 여러 위치에 불기둥·폭발·연기를 시차로 배치한다.

**권장: 천체 붕괴형 운석 폭격.** 큰 외곽 룬, 반대로 도는 점성술 고리, 내부 삼각/다각형 문양을 서로 다른 높이에 겹친다. 핵은 주황·백열색, 껍질은 검은 암석과 용암 균열로 만들고 꼬리는 길이와 각도가 다르게 한다. 7개 주요 운석은 서로 다른 높이·각도·시간차로 낙하시키며, 주변에는 작은 낙하 잔상과 파편을 분산한다. 적중은 짧은 섬광 → 납작하게 퍼지는 지면 충격파 → 튀는 암편 → 낮은 잔불 순서로 설계한다. 마지막 한 발의 크기와 충격파를 크게 해 끝맺음을 준다.

대안으로 **운석 폭풍형**은 작은 운석을 넓고 빠르게 난사해 난잡함을 강조할 수 있다. 반면 개별 타격의 무게는 천체 붕괴형보다 약해진다. 원하는 '마구 떨어지는 느낌'에는 권장안의 큰 7타격과 무작위처럼 배치한 작은 주변 연출을 결합하는 쪽이 적합하다.

주요 피해 이벤트 7회와 서버 범위 6은 유지하고, 주변 운석은 연출용으로 분리하는 설계다. 무작위 배치는 재생마다 무제한 입자를 만들지 않고 고정된 불규칙 좌표·시차를 이용하면 검증과 성능 관리가 쉽다. 현재 메테오 스크립트·소리·색상 `#CF4A7F`에는 이 제안을 적용하지 않았다.
