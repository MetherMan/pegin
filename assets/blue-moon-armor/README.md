# 푸른달 갑옷 (푸른달의 트와일라잇 세트 방어구)

## 현재 적용: 블랙나이트 바탕 (2026-10-01)

엘프 바탕은 게임에서 싸 보이고 가슴 초승달이 늘어져 보인다는 의견으로 **블랙나이트 세트 모양 그대로**(남 `ma_*_b032`, 여 `fe_*_b034`, Rank 6 모델)에 푸른달 색을 입혀 교체했다(`tools/build_bluemoon_bk_armor.py`, `index.html?data=bk-bluemoon`, 적용 카드 `D + 초승달 · 등판 정리`).

- 색: 엘프에서 고른 D 기준(흑남 바탕, 밝은 청은빛 판금). 블랙나이트 원래 텍스처가 어두워 꽤 밝게 나온다. 비교용으로 A 기준 카드도 남겼다.
- 초승달: 바깥 가슴판(남 `ma_tor_b032` 앞, 여 `fe_tor_b034_1` 앞)에 엘프 때보다 조금 작게(남 0.062, 여 0.045).
- 등판: 남자 블랙나이트 등은 회색 V자 판금 아래 어두운 가죽·끈이다. 밝은 색이 가죽까지 덮고 등에 빛나는 초승달 원판이 붙으니 아이언맨 가면처럼 보였다. 등 원판을 빼고 등 위쪽(몸통 본체의 뒤를 향한 면, 높이 1.12 이상)만 더 어두운 기준(Otsu 115%)으로 다시 칠해 가죽은 짙은 남색, V자 판금은 밝게 둔다. 무늬를 흐리게 뭉개는 방식은 회색 얼룩이 되어 버렸다. 여자는 등이 트인 끈 디자인이라 해당 없음.
- 게임 파일(`tools/bluemoon_armor_native.py`): 블랙나이트 MOD의 행렬·재질·스키닝을 그대로 두고 텍스처 이름만 `*_b050*`로 바꾼다. 여자 몸통·하의 인종 2벌(b150/b250, 원본 `fe_*_b134/b234`와 같은 방식), 땅 모델 `Body/Sub/*_b050_2.mod`. 남자 몸통은 텍스처 3장(`ma_tor_b050`, `a`, `b`). 엘프 때 쓰던 `ma_tor_b050c`·`fe_tor_b050a`는 지웠다. 아이템 번호·능력치·이름·재뽕 창고 위치는 그대로이며 아이콘은 새 모델로 다시 그렸다.

아래는 엘프 바탕으로 처음 등록할 때의 기록이다.

확정안(엘프 + 블랙나이트 견갑, A 텍스처, 가슴·등 초승달)을 실제 게임 파일로 만들어 등록했다. 이름과 Rank 색은 트와일라잇 무기와 같은 `#72CFFF`, Rank 9.

- 능력치: 강화 단계와 수치 열마다 `블랙나이트 × 단계비²`. 단계비는 같은 부위·같은 열의 블랙나이트(Rank 6) / 레드나이트(Rank 5) 비율이며, 단계마다 들쭉날쭉해(+1이 +0보다 낮아짐) 21단계 비율의 직선 맞춤을 쓴다. 즉 블랙나이트보다 두 랭크 위다. 기존 Rank 9 트와일라잇 양손검도 블랙나이트 양손검보다 같은 만큼(+0 ×1.68, +20 ×1.75) 높다. 데이터상 블랙나이트는 Rank 6, 레드나이트는 Rank 5다.
- 착용 직업·무게·맨살 여부는 블랙나이트와 같다(전사, 힘이 가장 높은 캐릭터). 가격도 같은 식으로 올렸다.
- 강화: 코드 수정 없이 기존 규칙 그대로다. 카드 강화는 번호+1과 단계 열을 보고 방어구 성공 확률표(목표 단계별)를 쓴다. GM `/재뽕 갑옷|바지|장갑|신발 N`용 강화표(`gm_enhance_data.h`)에 84개를 추가했다.
- 모델(`tools/bluemoon_armor_native.py`): `Body/High/{ma,fe}_{tor,leg,gun,boo}_b050_1.mod`. 몸통은 엘프 모델 + 블랙나이트 견갑 삼각형(남 576, 여 296)이며 미리보기와 같은 좌표다(등록 시 정점·면 수와 좌표 합을 대조). 여자 몸통·하의는 맨살이 보여 게임이 얼굴 인종에 따라 `b150`/`b250`도 읽으므로 맨살 텍스처만 다른 두 벌을 더 만들었다(원본 `fe_*_b111/b211`과 같은 방식). 땅에 떨어진 모델은 `Body/Sub/*_b050_2.mod`(엘프 모델 + 새 텍스처).
- 텍스처: 확정 PNG(`elf/<LOOK>-*.png`)를 `Texture/Body/*_b050*.wtm` 12장으로 넣었다. 원본 엘프·블랙나이트 파일은 바꾸지 않았다.
- 색 조정(2026-10-01, 첫 배포 뒤): 게임에서 A 색이 파란 쫄쫄이처럼 보인다는 의견. 하이라이트를 낮추고 채도를 올린 B·C를 비교한 뒤, 반대로 밝은 부분을 늘리기로 해 **D**를 적용했다(`bluemoon_armor_native.LOOK = 'bright'`). 같은 색 계열에서 밝은 판금으로 보는 기준을 Otsu 값의 80%→68%로 낮추고 판금 중앙 밝기 0.45→0.53, 바닥 0.42→0.47로 올렸다. 더 밝은 E(56%, 0.60/0.52)는 시안으로 남겨 둔다(`index.html?data=elf-bluemoon`). 모델·능력치는 그대로이고 텍스처·아이콘만 바뀌었다.
- 아이콘(`tools/build_bluemoon_armor_icons.py`, `icons/`): 새 모델을 8배 크기로 그려 28×28로 줄이고 블랙나이트·트와일라잇 무기와 같은 검은 바탕 + 금색 테두리에 넣었다. 몸통은 T자 기본 자세의 위팔을 내려 견갑과 가슴만, 바지는 허리~무릎, 건틀렛은 한 손만 보인다.
- 이름 색: `Engine.dll`의 트와일라잇 범위 검사(19030~19110) 세 곳에 19140~19250을 더했다(`.bmarm` 섹션, `tools/patch_bluemoon_armor_colors.py`). 사이의 스킬북·말 소유증서·물약 색은 그대로다. 두 적재 주소에서 160개 경우 확인.
- 재뽕 창고: `세트` 탭에 네 번째 묶음 `푸른달 트와일라잇`을 추가했다. 윗줄에 양손검, 둘째 줄에 롱보우·스태프, 전사 옷 줄에 아머·팬츠·건틀렛·부츠.

## 황금 세트 푸른달 색 시안

사용자 선택으로 황금 세트(남 `ma_*_b003`, 여 `fe_*_b001`)를 바탕으로 정했다. 형태는 그대로 두고 텍스처 색만 바꾼 두 시안을 `index.html?data=golden-bluemoon`에서 원본과 비교한다.

3차 조정(사용자: 어두운 부분은 흑남색, 밝은 부분은 흰색에 가까운 푸른색으로 확실히 차이): 재질(금판/천·사슬)마다 Otsu 기준으로 밝기를 어두운 바탕(사슬·가죽·그늘)과 밝은 표면(판금·천)으로 나눴다. 어두운 바탕은 흑남색(#02040c~#0d1c56), 밝은 표면은 중앙값이 선명한 파랑(#1f4cb4~#4a84e2)에 오고 가장 밝은 하이라이트만 흰빛 푸른색(#e4eeff~#f8fbff)이 된다. 판 모서리(녹청 부분)는 한 단계 더 밝게 둔다.

- A 흑남 / 백청: S-곡선 1.5.
- B 흑남 / 백청 (대비 더 강하게): S-곡선 2.3, 중간 톤을 줄여 흑남색과 흰빛 푸른색 차이를 최대로.
- 여자 세트의 맨살 텍스처(`Girl_torso_0-1`, `Girl_leg_0-`)는 바꾸지 않았다. 흰 천·흑자색·청색 치마는 차가운 톤으로 맞췄다.

재생성: `runtime/python/python.exe -B -X utf8 tools/build_bluemoon_golden_armor.py`(먼저 `build_armor_compare.py`). 미리보기용 PNG만 `golden/`·`elf/`에 있으며 게임 텍스처·아이템 등록은 하지 않았다. 확정 후 새 텍스처 이름으로 별도 MOD/WTM과 아이템을 등록해야 원본 황금 세트가 바뀌지 않는다.

## 엘프 세트 푸른달 색 시안

황금 세트와 같은 흑남 / 백청 기준(A·B)을 엘프 세트(남 `ma_*_b008`, 여 `fe_*_b011`)에 적용해 `index.html?data=elf-bluemoon`에서 원본과 비교한다. 엘프 강철판은 회색·올리브빛이라 색상으로 재질을 나누면 남녀가 다르게 잡히므로, 맨살을 뺀 텍스처 전체를 한 재질로 보고 어두운 바탕(가죽·사슬·그늘) → 흑남색, 밝은 강철판 → 선명한 파랑, 하이라이트 → 흰빛 푸른색으로 나눴다. 여자 맨살 텍스처는 유지.

2차(사용자: 어두운 부분이 너무 많음): 엘프만 판금 기준을 Otsu 값의 80%로 낮춰 더 많은 면적을 파랑으로 두고, 남은 어두운 바탕도 새까만 흑남색 대신 짙은 남청색(색 범위 0.16~0.40)으로 올렸다. 판금 중앙값도 조금 밝은 파랑으로 맞췄다. 황금 세트는 이전 값을 유지한다(`BASES`의 `tone`).

### 랭크 9 꾸미기 (엘프)

`tools/bluemoon_armor_decor.py`가 실제 갑옷 메시로 텍스처의 각 위치가 몸 어디에 놓이는지 계산한다.

- 등판: 남자 엘프 갑옷은 원본에서 등판을 앞판보다 어둡게 칠해 색을 바꾼 뒤에도 칙칙한 남색이었다. 등을 향한 몸통 면만 따로 밝기 기준을 잡아 앞판과 같은 파랑·하이라이트가 되게 했다.
- 초승달 문양: 가슴과 등의 몸 중앙선(남 가슴·등 높이 64%, 여 배 판금 45%·등판 50%)에 뿔이 위를 향한 초승달과 작은 네 갈래 별을 그 면의 크기·방향에 맞춰 그렸다. 남색 테두리와 하늘색 빛 번짐이 있어 밝은 판 위에서도 보인다. 좌우 대칭 모양이라 남자 등판처럼 반쪽만 그려진 텍스처도 온전한 문양으로 보인다.
- 테두리 빛 선은 분필로 그은 것처럼 보인다는 의견으로 뺐다(`bluemoon_armor_decor.outline`은 남겨두고 호출하지 않음). 다리·부츠의 흰 무늬는 원본 엘프 갑옷의 각인 무늬다.

### 형태 변경 (엘프 → 푸른달 랭크 9)

### 선택: 블랙나이트 견갑 + 새 텍스처 (2026-10-01)

사용자가 블랙나이트 견갑 버전을 골랐다. 튀어나온 가슴 메달은 뺐다(그려 넣은 가슴·등 초승달 문양은 유지). 페이지는 원본 / 블랙나이트 견갑·이전 텍스처 / 블랙나이트 견갑·새 텍스처 3칸으로 비교한다(`build_elf`).

새 텍스처(`elf_texture(..., polished=True)`):
- 원본 텍스처의 거친 얼룩을 3픽셀 중앙값 필터로 정리한 뒤 푸른달 색을 입힌다.
- 가장 밝은 각인선은 흰색 대신 은빛 푸른색(#bcd3f3~#d6e6fb)에서 멈춘다(`POLISHED`).
- 실제 갑옷 면 방향(정점 법선을 텍스처에 보간한 `normal_map`)으로 위에서 고르게 내려오는 빛과 앞·뒤에서 보이는 광택을 굽는다(`polish`). 좌우 대칭이라 반쪽 UV를 공유하는 면도 같은 결과이고, 뒷면이 어두워지지 않는다.
- 옮겨 붙인 블랙나이트 견갑 텍스처에도 같은 처리를 한다.

### 확정안 (2026-10-01)

사용자가 새(광택) 텍스처보다 이전 텍스처를 선호해 **A 색 + 블랙나이트 견갑**으로 확정했다. 페이지는 원본 / 확정안 두 칸이다.

앞판 초승달이 찌그러져 보이던 문제: 문양을 한 삼각형의 UV 기준으로 그려, 가슴판 UV가 부위마다 다르게 늘어난 만큼 휘어 보였다. `emblem3d`는 텍스처의 각 텍셀이 놓이는 실제 3D 위치(`position_map`)를 정면(뒷면) 시점으로 투영해 문양 좌표를 계산하므로 UV가 어떻게 늘어나 있어도 정면에서 동그랗게 보인다. 문양 뒤에 짙은 남색 원판과 얇은 하늘색 테두리를 깔아 가슴판의 원래 각인이 문양을 가로지르지 않게 했다.
